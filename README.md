<h1 align="center">Моя панель</h1>

<p align="center">Живая шторка сверху экрана и панель по <b>Alt+Пробел</b> для Windows 11.<br>
Плеер для всего, переводчик, заготовки, ссылки, скриншоты, полка для файлов, заметки, таймер и календарь — в одном месте.</p>

<p align="center"><a href="../../releases/latest"><b>⬇ Скачать последнюю версию</b></a></p>

---

## Установка

1. Открой [Releases](../../releases/latest) и скачай `MyPanel-Setup-<версия>.exe`.
2. Запусти. Windows может показать «Windows защитила ваш компьютер» — программа без платной подписи. Нажми **Подробнее → Выполнить в любом случае**.
3. Права администратора и Python не нужны. После установки панель сама откроется и покажет, что умеет.

Обновления панель находит сама: шестерёнка → «О программе» → «Обновить».

## Что умеет

| | |
|---|---|
| **Живая шторка** | Маленький «остров» у верхнего края: часы, музыка с эквалайзером под настоящую громкость, таймер с обратным отсчётом, ближайшие события календаря. Тянется к курсору и раскрывается в панель. |
| **Плеер** | Видит всё, что играет в Windows: Яндекс Музыку, Spotify, YouTube в браузере. Громкость системы и отдельного приложения, выбор устройства вывода. |
| **Переводчик** | Скопировал текст — он сам появился и перевёлся (русский ⇄ английский). |
| **Тексты и ссылки** | Заготовки вставляются в окно, где ты печатал; сайты, папки и файлы — в один клик. |
| **Скриншоты** | Последние снимки `Win+Shift+S`: клик — вставить, можно перетащить в чат. |
| **Полка для файлов** | Тащишь файл к верхнему краю экрана — шторка превращается в «Положить на полку». |
| **Заметки** | Мысль → Enter. Файл дня в выбранной папке (можно в Obsidian). |
| **Рисование** | `Alt+S` — пометки поверх экрана. |
| **Настройки** | Тёмная тема, какие вкладки показывать и в каком порядке, браузер, календарь Google (по iCal-ссылке), автозапуск. |

## Горячие клавиши

| Клавиши | Что делает |
|---|---|
| `Alt+Пробел` | открыть / закрыть панель |
| `Ctrl+1…7` | вкладки |
| `Esc` | закрыть |
| `Alt+S` | рисовать поверх экрана |

## Приватность

Всё хранится у тебя на компьютере (`%APPDATA%\MyPanel`). В интернет уходит только: текст для перевода (Google Translate), загрузка календаря по твоей ссылке и проверка новой версии на GitHub.

## Сборка из исходников

Нужны Python 3.12, [Inno Setup 6](https://jrsoftware.org/isinfo.php) и зависимости:

```powershell
py -3.12 -m pip install -r requirements.txt pyinstaller
py -3.12 panel.py                 # запустить из исходников
powershell -File builduild.ps1  # собрать установщик → release```
